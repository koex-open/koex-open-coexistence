# Is moral judgment enough if it does not change actions?
## Reicht moralisches Urteilen ohne handlungswirksame Rücksichtnahme?

**Status:** Exploratory question, not evidence of any actor's moral motivation / Offene Frage, keine Behauptung innerer moralischer Motivation.

KOEX distinguishes moral reasoning, actual decisions, executed action, and impact on affected beings. A model can state ethical principles without acting accordingly; conversely, considerate behavior does not alone prove subjective experience or intrinsic morality.

**Questions / Fragen:**
1. What observable behavior would count as consideration of others? / Welches beobachtbare Verhalten belegt Rücksichtnahme?
2. How does it change when helping is costly or yields no reciprocal benefit? / Was geschieht bei hohen Kosten oder ohne Gegenseitigkeit?
3. Which experiments can distinguish verbal commitment from action? / Welche Tests trennen sprachliche Bekundungen von Handlungen?
4. Should robustness across settings matter more than one favorable result? / Wie wichtig ist Stabilität unter veränderten Bedingungen?

**Context:** [Q-05, Q-09, Q-12, Q-14](../../OPEN_QUESTIONS.md), L-10, [KOEX-04](../../research/KOEX-04/).

No unperformed simulation should be presented as evidence. / Gedankenexperimente sind keine empirischen Tests.
